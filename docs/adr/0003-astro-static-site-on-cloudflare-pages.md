# Build with Astro as a static site, hosted on Cloudflare Pages

The site is a static site generated by Astro and deployed to Cloudflare Pages from the
GitHub repo. Astro was chosen over Hugo/Eleventy/Jekyll because v1 wants genuinely
interactive recipe pages (cook mode, serving scaler, unit toggles, tap-to-check, timers)
and Astro's component islands deliver that interactivity with minimal shipped JS, while
its Content Collections + Zod give us typed, validated recipe frontmatter that catches
intake mistakes. Cloudflare Pages was chosen for hosting because it has unlimited
bandwidth, free SSL + custom domain, no commercial-use restriction, and no surprise-bill
risk; GitHub Pages is the acceptable fallback. We rejected self-hosted recipe apps
(Mealie, Tandoor) as overkill — a 24/7 server + database + patching for meal-planning
features we don't want.

## Consequences

- We own the recipe-page UI and the schema.org JSON-LD template rather than getting them
  from an app — more control, but we build them.
- Avoid Vercel Hobby (non-commercial clause) and be wary of Netlify's tightened free tier.
